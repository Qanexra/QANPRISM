# QanPrism Technical Architecture

## Overview
QanPrism is designed around three core principles:
1. **Low Resource Consumption**: Utilizing OS-native webviews via Tauri & Rust IPC.
2. **Modular Data Pipelines**: Allowing users to connect free/paid financial data feeds seamlessly.
3. **Provider-Agnostic LLM Routing**: Unified protocol support for local (Ollama) and cloud APIs.

## Security & Privacy Model
- **Local-First Design**: API keys and session history are stored locally in an encrypted vault (`~/.qanprism/vault.enc`).
- **Air-Gapped Execution**: When connected to local Ollama endpoints (`http://localhost:11434`), no external network traffic is generated by the AI agent.
